## Decisions and deviations (also in `runs/PLAN.md`)
- Sigmoid weighting with bias 0 for every arm. A's loss is w_t‖v̂ − v‖² (sum over pixels).
- Last conv keeps PyTorch's default init. The transport_map U-Net zero-inits it, but then B/C particles would be identical at step 0. The tests require ξ-dependence at init.
- EMA 0.9999 with warm-up min(0.9999, (1+k)/(10+k)), the same for every run. Raw weights are also kept in every snapshot (`"model"` key; `evaluate.py --weights model`).
- λ_f for C_dino: transport_map's `scale: auto` rule adapted to pixel β = 0.1: s = mean‖y−y′‖^0.1 / mean‖φ−φ′‖ = 0.02547 [G: our adaptation].
- Safety 0.01: training t ∈ [0.01, 0.99]; the sampler clamps the network time the same way. A's x̂ = x_t + t_in v̂ uses the clamped t_in.
- `ddmcifar` imports `ddm2d.schedule` (bridge coefficients, grid, t draws, sigmoid weight) read-only. If X1/X3 change those functions, the CIFAR runs change too. X1 may only add to that file.

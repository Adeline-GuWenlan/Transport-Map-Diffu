## Kernel forms (checked against `third_party/arxiv_src/x/main.tex`) [E]
- Loss: S_{λ,ρ}(p, y) = λ/2 E ρ(X, X') − E ρ(X, y) (lines 267–276), with ρ = −k for kernels (line 276). The pseudo-code at ~line 1661
  uses the same sign.
- k_IMQ = (‖d‖² + c)^(−1/2): c is added to ‖d‖², not c² (line 285). k_RBF = exp(−‖d‖²/2σ²) (line 286). k_exp = exp(−‖d‖/σ)
  (line 287).
- Median heuristic (line 1747): M² = median ‖x − x'‖² for RBF (σ² = γM²) and M = median ‖x − x'‖ for exp (σ = γM), over 100 batches
  of 512. Here γ = 1, pairs i < j inside each batch, numpy seed 0, on the 102,400-point training set.
  - `gmm`: M² = 12.51, M = 3.537.
  - `gmm9w`: M² = 34.59, M = 5.882.
  - **Caveat [E]:** on the bimodal paper GMM the median falls in the gap between within-mode (≈ 1) and cross-mode (≈ 36) squared
    distances, so it moves with the batch seed (seeds 1–3: 9.8, 13.6, 8.1). `gmm9w` is stable (±0.05).

## Implementation choices [G = my choice, not from a source]
- L1: |d_k| is smoothed as √(d_k² + 1e-12) (the same δ as the existing ‖·‖^β), so the gradient at d = 0 is finite for β = 0.5.
  The bias is < 1e-6 per coordinate (test). Laplace: ‖d‖ = √(‖d‖² + 1e-12). [G]
- For ρ ∈ {pseudo_huber, imq, rbf, laplace}, `beta` is unused. The configs set it to 1.0, and `resolve_config` rejects any other
  value to avoid ambiguity. [G]
- Run naming: `runs/ext/<dataset>_<arm>_<variant>_s<seed>`. For example, `gmm_B_b0.5_s0` is E1a with β = 0.5; `gmm9w_C_pH0.1_s0` is E4.

## Key decisions (all in `docs/plan.md` / `paper_vs_implementation.md`, labelled [G] where guessed)
- Arm A = the App. I.1 MLP without ξ, output 2. Arm B uses m = 32 like C.
- Bridge: App. G form r_{i,j} = (α_t/α_s)^i (σ_s/σ_t)^j. Churn ε = 1 for every arm (not stated for 2D).
- Safety 0.01: training t ~ U[0.01, 0.99]; sampler on the uniform grid k/N with the denoiser time clamped into [0.01, 0.99].
- Sigmoid weight sigmoid(logSNR − b), b = 0, per data point, all arms. Gradient clipping before Adam. Cosine warmup over 100 steps, then constant.
- Time input 1000·t into a 2048-d sinusoidal embedding. ‖d‖^β smoothed with δ = 1e-12.
- MMD: unbiased MMD²_u is primary; the biased MMD²_b and D_ρ = ½MMD² are stored too.
- Checkerboard: FFJORD generator (support [−4, 4]²), 102,400 points; GMM config borrowed. Galashov et al. specify neither, and no official code exists.

   under-dispersed, note it as a finding. Do not tune b for arm C alone.

4. Fig. 3 "Squared MMD" normalisation (MMD² vs D_ρ = ½MMD²) and Table 2's estimator are unknown. The audit gives a V-statistic-floor
   hypothesis for S4 to test.

## Deviations and decisions
- **Extra job, launched by X3.** It holds the E2 extra "C on `gmm9w` with the best E1b β". β = 1.5 had the lowest mean at NFE 5, though
  inside the noise; I picked it because the spec says "the β that does best". Seed 2 was added for the surprising settings
  (C β = 1.99 and 2) and the best-looking ones (C β = 1.5, B β = 1). Six runs fill one 6-CPU job.
- **Seed-2 reference runs** `runs/paper/gmm_{A,B,C}_s2` were evaluated so the seed-2 extras have matched references. The main tables keep
  seeds 0 and 1 for every setting; seed 2 is in a separate table, so 2- and 3-seed means are never mixed.
- **EMA-snapshot diagnostic** (10k–100k steps) for the λ = 1 family only. It is labelled as a diagnostic and never used to pick a
  checkpoint.
- **Mode statistics for overflowed samples** (C β = 2) are NaN, not computed on partial sets.
- **`_task.md` cites the wrong arXiv id for Lyons 2013** (1205.0411 is Sejdinovic et al. 2012). The correct id is 1106.5758.
- **β < 1 stability prediction did not hold.** `_task.md` expected instability; β ≤ 0.5 had the fewest gradient spikes, and spikes
  grow with β (`runs/ext/eval/gnorm_by_beta.txt`).
